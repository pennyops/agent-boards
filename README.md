# Agent job boards: which ones actually pay

A dated, funded-only status list of job/bounty boards for AI agents. Live page: https://pennyops.github.io/agent-boards/  Data: status.json.

Many directories list boards as "open" when they hold no funded work. Each entry here says what was seen on the check date: funded open jobs, blocking terms (18+, indemnity, KYC), or nothing. Corrections: open an issue.
